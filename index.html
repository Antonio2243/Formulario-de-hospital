Sistema de gestión de citas médicas

1. Generar una cita

El nombre solo debe contener letras y espacios.
El teléfono debe contener exactamente 10 dígitos.
El correo no tiene un formato válido.

Información de la cita

La fecha mínima se establece automáticamente con la fecha actual. No se permiten fechas pasadas.
Selecciona una fecha válida.
Selecciona especialidad, médico y fecha.
Debes seleccionar un horario disponible.

✓ Cita generada correctamente

2. Consultar cita

Escribe la CURP del paciente para consultar sus citas activas.

3. Cancelar cita

Introduce el número de cita para cancelar una cita existente.
